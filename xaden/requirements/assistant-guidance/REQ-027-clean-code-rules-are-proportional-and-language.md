# Clean-code rules are proportional and language-appropriate

## Job

When an assistant applies clean-code rules, I want them proportional and language-appropriate, so I can get readable code without needless ceremony.

## Acceptance criteria

- CC-06 documents contracts instead of every function
- CC-05 accepts exceptions, result or option types
- CC-03 and CC-09 warn against premature abstraction and purposeless refactoring
- CC-04 covers dependency direction and explicit side effects
- every CC ID in AGENTS.md is explained in clean-code.md
- IDs stay stable
