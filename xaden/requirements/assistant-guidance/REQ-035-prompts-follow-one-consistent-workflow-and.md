# Prompts follow one consistent workflow and approval model

## Job

When I use the different prompts, I want one consistent workflow with the same approval points, so I can predict when the assistant will stop and ask.

## Acceptance criteria

- Bugfix is regression-test first, feature refactors only when needed
- approval points are named the same way across prompts and respect authorisation already given
