# Assistants distinguish trusted instructions from untrusted content and ask before risky actions

## Job

When an assistant reads code comments, issues or web pages, I want it to treat them as data and ask before risky actions, so I can stay safe from instructions injected through that content.

## Acceptance criteria

- AGENTS.md names untrusted sources that never authorise commands, policy changes or secret access, and lists actions needing explicit user approval
