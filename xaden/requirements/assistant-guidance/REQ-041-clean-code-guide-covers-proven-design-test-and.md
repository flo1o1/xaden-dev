# Clean-code guide covers proven design, test and refactoring practices

## Job

When an assistant designs, tests or refactors code, I want proven practices written down, so I can get maintainable code by default.

## Acceptance criteria

- clean-code.md adds composition root, do-or-know, polymorphism over repeated switches, temporal coupling, Law of Demeter, conditionals, size heuristics, test practices and test doubles, comment upkeep and language, refactoring techniques
- ESLint preset forbids var
- CC IDs unchanged
- nothing project-specific
