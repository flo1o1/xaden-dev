# The scaffold depends on no personal tools, skills or accounts

## Job

When I use a scaffold someone else wrote, I want it to depend on no personal tools, skills or accounts, so I can get the same results as its author.

## Acceptance criteria

- Scaffold and generated projects name no personal skills, plugins or private tools
- features work with what GETTING-STARTED.md lists as prerequisites
- a smoke test rejects named skills in the template
