# Security reviews produce a recorded report with evidence

## Job

When a security review is done, I want a recorded report with scope, evidence and limitations, so I can see what was really checked.

## Acceptance criteria

- Review prompt output has scope, evidence, limitations, findings and remediation status
- reports are stored from docs/security-reviews/0000-template.md
- a checklist is not presented as proof
