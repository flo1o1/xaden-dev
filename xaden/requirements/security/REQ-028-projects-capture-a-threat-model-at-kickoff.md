# Projects capture a threat model at kickoff

## Job

When I start a project, I want a threat model captured at kickoff, so I can base security decisions on my real assets and attackers.

## Acceptance criteria

- Template has docs/threat-model.md (assets, sensitive data, entry points, trust boundaries, attackers, deployment assumptions, ASVS level)
- kickoff fills it
- security review reads it
