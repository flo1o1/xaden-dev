# Documentation guidance is honest about checks and covers operations

## Job

When documentation passes its checks, I want to know what was and was not verified and to cover operations, so I can tell a structure check apart from correct content.

## Acceptance criteria

- Docs state check-docs.sh validates structure only
- documentation prompt and admin guide ask for timeouts, retries, cancellation, health checks, safe logs, migrations with rollback and tested restores where they apply
